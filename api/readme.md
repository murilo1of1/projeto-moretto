# INSTRUCOES DE USO

## Rode
```js
  npm install
```

## Coloque no .env

```js
  API_PORT=8080
  TOKEN_KEY=uma_chave_secreta_qualquer
  POSTGRES_DB=projeto_moretto
  POSTGRES_USERNAME=postgres
  POSTGRES_PASSWORD=password
  POSTGRES_HOST=localhost
  POSTGRES_PORT=5432
```

## Popule o banco (primeira vez / para resetar os dados de exemplo)
```js
  npm run seed
```

## Rode
```js
  npm run dev
```
